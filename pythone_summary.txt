 PYTHON SUMMARY

What is Python?

Python is a high-level programming language that is easy to learn and use.

Why do we use Python?

We use Python to create programs, websites, automate tasks, analyze data, and develop AI.

Advantages of Python:

Easy to learn.

Simple and readable.

Works on different operating systems.

Has many useful libraries.

Has a large community.

Disadvantages of Python:

Slower than some languages.

Uses more memory.

Not ideal for some mobile apps.

May need extra libraries.

WHAT IS PSEUDOCODE?

Pseudocode is a simple way to write the steps of a program using plain English.

PSEUDOCODE: READING A FILE

START

Set file name to "example.txt".

Open the file in read mode.

If the file opens, read its contents.

Display the contents.

Close the file.

Otherwise, display "File could not be opened".
